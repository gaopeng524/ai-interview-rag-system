# 00 · 项目总览

> 一句话：一个 **Spring Boot + Spring AI + DeepSeek** 的流式聊天 Web 应用，带 JWT 登录、会话管理、短期/长期双层记忆和天气函数调用。

## 技术栈

| 技术              | 版本/用途                                              |
| --------------- | -------------------------------------------------- |
| Spring Boot     | 4.1.0，Web 容器（内嵌 Tomcat 11）                         |
| Spring AI       | 2.0.0-M4（里程碑版），统一封装大模型调用                           |
| DeepSeek        | deepseek-v4-flash 推理模型（走 Spring AI 官方 DeepSeek 集成） |
| Spring Security | 7.1.0，JWT 认证                                       |
| MyBatis         | 数据访问，SQL 写在 XML 里                                  |
| PostgreSQL      | 长期记忆（数据库），跑在 Docker（pgvector:pg16）                 |
| JWT (jjwt)      | 登录凭证，token 里带 userId                               |

## 分层架构（铁律：依赖只准从上往下）

```
浏览器 index.html
  │  fetch + Authorization: Bearer <JWT>
  ▼
controller/   薄：只收参数、转发 Service，不做业务
  ▼
service/      厚：业务逻辑、归属校验、事务
  ├─► ChatResilienceService ──► ChatClient.stream() ──► DeepSeek
  │        └─ 记忆窗口 Map + Advisor
  └─► mapper/ ──► MyBatis ──► PostgreSQL
```

**核心原则**：Controller 能调 Service，Service 能调 Mapper 和另一个 Service，反过来不行。这是全项目所有改动反复强调的那条线。

## 一次完整请求的生命周期

### ① 登录（匿名可访问）
```
POST /users/login {username, password}
  → SecurityConfig 放行（仅注册/登录公开）
  → UserService.login：查用户 + BCrypt 比对
  → JwtService.generateToken()：userId 写进 token
  → 返回 JWT → 前端存 localStorage
```

### ② 流式对话（要 JWT）
```
POST /chat/sessions/5/messages {content}      ← 响应 text/event-stream
  → JwtAuthenticationFilter：解析 token → principal(userId, username)
  → ChatController.sendMessage → ChatService.streamChat(5, 1, content)
      ├─ 归属校验（不是自己的会话 → 403）
      ├─ 短期记忆空？→ 用 DB 历史预热（重启不丢上下文）
      ├─ 用户消息落库
      ├─ ChatResilienceService → ChatClient.stream() → DeepSeek 逐块返回
      │    → 每块打包成 {"type":"reasoning"/"content","text":…} 推前端
      │    → 只在整个流没吐出分片前才重试；中途断发 error 事件
      └─ 流结束 → ChatService 把 AI 正文落库（长期记忆）
```

## 怎么跑

```bash
# 前置：PostgreSQL(Docker ai-postgres) 在跑；DEEPSEEK_API_KEY 已设
export JAVA_HOME="D:/jdk17"     # 本机 JDK 无全局配置，每次新终端都要
./mvnw spring-boot:run          # 打开 http://localhost:8080
./mvnw -Dtest=ChatResilienceServiceTest test   # 跑单测
```
